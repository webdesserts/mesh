# Icons

The webdesserts icon suite's **mesh** glyph: two woven diamond rings, one
sepia-85 and one magenta, on the Neapolitan purple-15 plate with a 0.14 magenta
sheen. The other suite apps are notes (book), agents (diamond triad) and
feeds (origin + chevrons).

- `mesh.svg`: the app icon on a 512 canvas (plate 16..496, rx 112), with
  PNG renderings `mesh-{1024,512,256,128,64,32}.png`.
- `mesh-mark.svg`: the same weave in black on transparent, for a menu-bar
  template or a one-colour mark (`mesh-mark-44.png` = 22pt @2x).

Re-render the PNGs with resvg after editing an SVG, e.g.
`resvg -w 512 icons/mesh.svg icons/mesh-512.png`.
